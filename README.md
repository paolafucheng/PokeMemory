# PokeMemory

Es una aplicación web basada en el clásico juego Memory utilizando Pokémon como temática. La aplicación se desarrollará con HTML, CSS y JavaScript, sin frameworks de frontend, utilizando Vite. Los datos de los Pokémon se obtendrán mediante **PokeAPI utilizando fetch**.
